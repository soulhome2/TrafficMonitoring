# Ревью спецификации: реестр версий

## Правила версионирования

- Имя файла: `ГГГГ-ММ-ДД_vN.md`, где дата — день создания ревью, `N` — сквозной номер версии ревью (не сбрасывается при смене даты).
- Каждое новое ревью — новый файл. Предыдущие версии не переписываются; допускаются только отметки о статусе замечаний.
- В шапке каждого ревью указываются: объект ревью (файл и версия спецификации), предыдущее ревью, тип ревью.
- Идентификаторы замечаний уникальны в пределах версии ревью: v1 — `Р-N`, `Q-…`, `OQ-…`; v2 — `CR-NN`. При ссылке из спецификации указывать файл ревью и ID.
- После добавления ревью — дополнить таблицу ниже.
